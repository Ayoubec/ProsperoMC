# ProsperoMC artwork

Created with the built-in image generation tool for this project. The original
PNG files remain here; `scripts/prepare-artwork.py` encodes them into the native
UI's RGB565 header and the loader's icon/backgrounds. There is no runtime image
decoder or additional engine.

Icon prompt: a polished square PS5 homebrew launcher icon for ProsperoMC; a
compact isometric grass-topped voxel island with a luminous lime geometric
portal; forest green and near-black background, warm earth and stone, crisp
block forms and a silhouette readable at small sizes. No text, watermark or
official Minecraft/PlayStation logos.

Artwork prompt: wide cinematic voxel landscape for the home hero and launch
background; grass block cliffs, pine trees, a reflective river, distant block
mountains and a small luminous lime portal in the right-hand cliff. Forest
greens, near-black shadows, lime highlights and warm earth. Strong subjects on
the right, a quieter left side for text. No people, text, HUD or official logos.
